This page calculates the total hours worked for an employee in base of the respective shift or the hour of start and end of work.

This page also calculates the estimated salary of an employee based on the hours previously calculated.

This page uses vanilla JavaScript to make calculations, change design and set different variables to make a functional financial tool, avoiding the user to involve with complex calculations.

This page also contains a dark mode option.

Take a look of this tool <a href="https://workedhourcalculator.netlify.app/">here</a>
