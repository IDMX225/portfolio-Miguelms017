This Project shows a maze game created by <a href="https://phaser.io">phaser</a>.

The objective of this game is to find a key between a maze to open a door and pass to the next maze.

The mazes are created randomly as well as the key and door locations. This game was coded in JavaScript using phaser as the graphic engine.
